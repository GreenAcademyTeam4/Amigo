# Amigo Project
![logo](https://github.com/user-attachments/assets/1bf557c5-0c3b-4bb5-957f-6cd4395b47bb)

## 프로젝트 주제 선정이유?   
- 학창 시절을 지나며 초등학교, 중학교, 고등학교에서 만난 친구들이 문득 떠오를 때가 많습니다. <br>
그들과의 소중한 기억이 그리워질 때, 채팅으로 만날 수 있는 동창회 게시판 Amigo를 개발하게 되었습니다.

## 🙋‍♀️ 팀원

1. 송원석(팀장)
    - 화상채팅
    - 단체채팅
    - 학교 데이터 수집

2. 박정훈(부팀장)
    - 게시판 생성.수정,삭제,조회
    - 댓글 생성,수정,삭제,조회
    - 게시판,댓글 페이징 처리

3. 박준수(팀원)
    - 로컬,소셜 로그인
    - 회원가입
    - 화면UI/css

4. 도준영(팀원)
    - 마이페이지
    - 상점
    - 인벤토리
    - 친구
    - 대댓글

5. 이윤서(팀원)
    - 토스 API를 사용한 결제/환불
    - 1대1 채팅

6. 김민경(팀원)
    - 관리자 페이지
