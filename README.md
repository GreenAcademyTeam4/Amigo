## 프로젝트 주제 선정 이유

**Amigo 프로젝트**는 학창 시절의 추억을 소중히 여기는 이들을 위해 개발되었습니다. 초등학교, 중학교, 고등학교 시절 만난 친구들과의 추억이 문득 그리워질 때, Amigo는 그들과 다시 소통할 수 있는 공간을 제공합니다. 친근하고 편리한 동창회 게시판에서 채팅과 소셜 기능을 통해 친구들과 쉽게 연락을 이어갈 수 있습니다.

## 😀 프로젝트 소개

Amigo는 동창회와 친구 관리에 특화된 소셜 커뮤니티 플랫폼입니다. 사용자들은 이곳에서 게시판과 채팅을 통해 옛 친구들과 소통할 수 있습니다. 프로젝트의 주요 기능은 다음과 같습니다:

1. **다양한 커뮤니케이션 채널**: 화상 채팅, 단체 채팅, 1:1 채팅
2. **사용자 관리**: 로컬 및 소셜 로그인, 회원가입, 마이페이지 기능
3. **동창회 게시판**: 게시물 및 댓글 작성, 수정, 삭제, 페이징 처리
4. **상점 및 인벤토리 시스템**: 친구와 교류할 수 있는 기능 포함
5. **관리자 페이지**: 사용자 관리, 게시판 관리, 통계 제공

## 🗂 데이터베이스 설계

프로젝트의 데이터베이스는 H2를 기반으로 하며, MyBatis를 통해 효율적인 데이터 매핑을 수행하고 있습니다. 전체적인 데이터 구조는 아래 ERD를 통해 확인할 수 있습니다.

## 🛠 개발 환경 및 도구 소개

### 사용 기술 스택

- **백엔드 프레임워크**: Spring Boot
- **개발 툴**: Eclipse, VS Code, IntelliJ
- **데이터베이스**: H2 Database, MyBatis
- **템플릿 엔진**: Mustache
- **협업 툴**: Github, Figma, Notion, Discord

### 외부 라이브러리 및 기술

- **라이브러리**: jQuery, WebSocket, Jackson
- **외부 기술**: WebRTC (실시간 커뮤니케이션)
